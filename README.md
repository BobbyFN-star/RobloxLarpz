## ⚙️ Core Capabilities

* **Multi-Threaded Concurrency:** Optimized `ThreadPoolExecutor` pipelines designed to maximize request throughput without saturating network boundaries.
* **Batch Processing:** Bulk POST chunking (up to 50 names per request) leveraging official endpoints for maximum lookup speed.
* **Automated Archiving:** Real-time `.txt` file logging complete with direct, clickable search redirects for every discovered handle.
* **Webhook Integration:** Instant live alerts dispatched directly to your Discord or custom webhook endpoints for every successful find.
